# FITORA Client — Next.js 16 Frontend

This is the official frontend application for **FITORA**, built with **Next.js 16 (App Router)**, **TypeScript**, and **Tailwind CSS v4**.

---

## 🌟 9 Core Feature Routes

1. `/(main)` — **Homepage**: Luxury monochrome landing page with hero banner, trainer gallery, and trial booking.
2. `/calculator` — **Metric & BMI Calculator**: Real-time BMI, BMR, and TDEE calculation.
3. `/dashboard` — **Unified Central Dashboard**: Role-based access control (RBAC) supporting Master Admin, Branch Admin, and Member views.
4. `/dashboard/login` — **Enterprise Security Gateway**: High-security 1-page zero-scrolling login portal.
5. `/exercises` — **Exercise Library & Tracker**: Strength, cardio, and hypertrophy movement catalog.
6. `/login` — **Consumer Login**: Member authentication powered by Better Auth.
7. `/meals` — **Meal Plans**: Nutritious recipe catalog with modal macro breakdown.
8. `/register` — **Member Registration**: Prospective athlete signup.
9. `/stopwatch` — **Gym Stopwatch & Rest Timer**: Fullscreen timer with audio alerts and quick intervals.

---

## 🛠️ Local Development

```bash
# Install dependencies
npm install

# Run the local development server
npm run dev

# Check TypeScript types
npx tsc --noEmit

# Build production bundle
npm run build
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore the platform.
